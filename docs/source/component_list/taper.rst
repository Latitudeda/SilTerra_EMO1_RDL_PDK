TaperLinear
**********************************************************
.. image:: ../images/taper_linear_strip.png

+----------------+-----------------+------------------------------------------------------------------------------------+
| Parameters     | Range           | Description                                                                        |
+================+=================+====================================================================================+
|length          |  > 0            | Length of Taper                                                                    |
+----------------+-----------------+------------------------------------------------------------------------------------+
|left_type       |  --             | Type of waveguide of start                                                         |

|right_type      |  --             | Type of waveguide of end                                                           |

+-------------------+-----------------------------+-------------+
|     ports         |   default waveguide type    | orientation |

TaperParabolic
**********************************************************

+----------------+-----------------+------------------------------------------------------------------------------------+
| Parameters     | Range           | Description                                                                        |
+================+=================+====================================================================================+
|length          |  > 0            | Length of Taper                                                                    |
