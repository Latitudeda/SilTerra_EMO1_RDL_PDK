auto_vias.py
====================

Define the vias between different metal line type.

In SilTerra PDK, the vias array of the ``UTV`` layer will be added when the connection is made between the metal lines of the ``UTM`` layer and the ``UTM2`` layer.

Users are allowed to define vias and change related parameters by their own specific requirements. Please see ``technology > vias.py`` and ``components > via > vias.py`` to modifiy the default vias.
