__init__.py
===================

Define the WG class which consists of ``STRIP.C.WIRE`` / ``LRIB.C.WIRE`` / ``HRIB.C.WIRE`` class. The width of the waveguide is set here according the parameters in ``constant.py`` file. **PhotoCAD** also support CD bias control of the waveguide width. The CD bias setting can be implemented in ``strip.py`` / ``lrib.py`` / ``hrib.py``.
